# 前端动效参考库

这个目录用于保存 Do Not Miss 前端改造时可以复用的视觉、动效、交互参考。

核心目的不是简单复制代码，而是建立一套“视觉词汇表”：

- 用户说“融合特效”，可以定位到对应参考代码和实现思路。
- 用户说“碰撞粒子特效”，可以定位到可复用的粒子交互方案。
- 用户说“像某个网站那种高级拖拽”，可以定位到对应交互细节、状态和动画节奏。

## 推荐目录结构

- `效果索引.md`：所有效果的入口索引，记录触发词、适合页面、实现状态。
- `代码片段模板.md`：以后新增参考效果时复制这个结构填写。
- `snippets/`：每个具体效果一个文件，保存参考代码、视觉描述、改造方案。
- `assets/`：如果后续有截图、视频、GIF、图片素材，可以放这里。

## 使用原则

- 记录来源：如果代码来自网站、开源项目或文章，要写清楚来源和许可证信息。
- 不盲目照搬：参考代码只作为视觉和交互依据，最终要适配 Do Not Miss 的 Vue 前端结构。
- 拆清楚效果：把颜色、布局、动效、交互逻辑、数据绑定拆开记录，方便局部复用。
- 注意性能：粒子、Canvas、WebGL、大量动画需要记录性能风险和降级方案。
- 注意版权：商业站点代码只做学习参考，不直接复制受版权保护的完整实现。

## 推荐记录粒度

一个词条最好回答这些问题：

- 这个效果长什么样？
- 用户会怎么描述它？
- 适合用在哪个页面？
- 需要哪些技术：CSS、Vue Transition、Canvas、Three.js、GSAP、Framer Motion 等。
- 哪些代码可以复用？
- 哪些地方必须重写？
- 在 Do Not Miss 中怎么落地？
